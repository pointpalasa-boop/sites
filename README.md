# sites

Демонстрационные макеты сайтов. Все бренды вымышленные, данные условные. Каждый сайт — своя папка с `index.html`, открывается без сборки.

| Папка | Что это |
| --- | --- |
| `demo/` | Круглосуточная стоматология |
| `dymka-coffee/` | Кофейня и обжарка «Дымка», тёмная тема |
| `temp-run-club/` | Беговой клуб «Темп», яркий необрутализм |
| `vydokh-yoga/` | Студия йоги «Выдох», светлый минимализм |
| `loft-photo-studio/` | Фотостудия «Лофт 9», переключатель тёмной и светлой темы |
| `khlebnitsa/` | Пекарня «Хлебница»: `before.html` — типичный сайт с ошибками, `index.html` — исправленный |
| `proverka-sayta/` | Лид-магнит «Проверь свой сайт за 10 минут»: страница с онлайн-проверкой (`index.html`), `checklist.pdf`, `build.py` (пересборка с вашим контактом) |
